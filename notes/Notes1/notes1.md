# What is Markdown?

Markdown is a markup language that lets you write plain text documents with a few lightweight formatting options. It focuses on the content, so the user does not have to worry about tags like in HTML. Markdown was created by John Gruber in 2004. Markdown files use the .md or .markdown file extension. In this class, we are using GitHub Flavored Markdown (GFM).

# What is Git?

Git is a version control system that we will use to keep track of all the work that we do in the course. It allows changes to files and projects to be tracked over time.

# What is GitHub?

GitHub is a cloud version control system where we will save our work in case the computer breaks. It can be thought of as cloud storage or a drive for code, text files, and other related files.

# What is Slack?

Slack is a communication and collaboration platform that allows users to communicate through messages and channels. It can be used to share information, files, and communicate with classmates and instructors.
