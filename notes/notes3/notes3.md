## Graphical User Interface (GUI)

A set of programs that lets the user interact with the computer through icons, windows, and other visual elements.

## Desktop Environment

A bundle of programs running on top of the operating system that shares a common GUI; it can be thought of as a graphical shell. Linux distributions can come with different desktop environments, with GNOME and KDE being common examples.

## Command Line Interface (CLI)

Allows you to interact with a computer by typing commands into a terminal instead of using graphical menus and buttons.

## How do I access the command line interface (CLI)?

In Linux, you can access the CLI by taking the system out of graphical desktop mode and place it in text mode.

## Virtual Console

A terminal session that runs in Linux system memory.

## Terminal Emulator

A program that allows you to access the Linux CLI when using the GUI.

## Bash

A program that provides interactive access to the Linux system.

## Shell Prompt

The shell prompt shows that the terminal is ready for you to enter a command.

# Definitions, Usage, Examples

## clear
* Definition: Clears the terminal screen
* Usage: clear
* Example: clear
## echo
* Definition: Displays text or a message in the terminal.
* Usage: echo "Hello World"
* Example: echo "Hello World"
## date
* Definition: Displays the current date and time.
* Usage: date
* Example: date
## free
* Definition: Displays information about the computer's memory usage.
* Usage: free
* Example: free -h
## uname
* Definition: Displays information about the operating system and computer.
* Usage: uname [option]
* Example: uname -a
## history
* Definition: Displays a list of commands that were previously entered in the terminal.
* Usage: history
* Example: history
## man
* Definition: Displays the manual page for a command.
* Usage: man [command]
* Example: man ls
## tldr
* Definition: Gives a simple summary and examples of a command.
* Usage: tldr [command]
* Example: tldr ls
## cheat
* Definition: Provides quick reference information for a command.
* Usage: cheat [command]
* Example: cheat ls
## hostname
* Definition: Displays the name of the computer on the network.
* Usage: hostname
* Example: hostname
## df
* Definition: Displays the amount of disk space available and used on the computer.
* Usage: df [option]
* Example: df -h

## du
* Definition: Displays the amount of disk space used by files and directories.
* Usage: du [option] [file or directory]
* Example: du -h

## figlet
* Definition: Displays text in large ASCII-style letters in the terminal.
* Usage: figlet [text]
* Example: figlet Hello
