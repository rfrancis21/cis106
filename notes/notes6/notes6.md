
# Notes 6: Linux File Management Commands

## 1. mkdir

**Definition:**  
The `mkdir` command creates new directories (folders) in the file system.

**Usage/Formula:**  
`mkdir [directory_name]`

**Examples:**
- `mkdir projects`
- `mkdir homework`
- `mkdir -p school/assignments/week6`

## 2. touch

**Definition:**  
The `touch` command creates an empty file or updates the timestamp of an existing file.

**Usage/Formula:**  
`touch [file_name]`

**Examples:**
- `touch notes.txt`
- `touch homework.md`
- `touch lab6.txt`2

## 3. rm

**Definition:**  
The `rm` command removes files or directories from the file system.

**Usage/Formula:**  
`rm [file_name]`

**Examples:**
- `rm oldfile.txt`
- `rm notes.txt`
- `rm -r old_folder`

## 4. cp

**Definition:**  
The `cp` command copies files or directories from one location to another.

**Usage/Formula:**  
`cp [source] [destination]`

**Examples:**
- `cp notes.txt backup.txt`
- `cp homework.txt Documents/`
- `cp -r projects/ backup/`

## 5. mv

**Definition:**  
The `mv` command moves files or directories to another location or renames them.

**Usage/Formula:**  
`mv [source] [destination]`

**Examples:**
- `mv notes.txt Documents/`
- `mv oldname.txt newname.txt`
- `mv homework/ Documents/`
